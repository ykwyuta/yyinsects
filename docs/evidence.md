# 休む場所・冬越しの裏付け

ゲームの「活動しない時間帯に休む場所」と「成虫の季節でないときの姿（冬越し）」について、出典で裏付けを確かめた結果です（2026年11月調べ）。

- ✅ 確認：その種（または「モンシロチョウ」「カブトムシ」のように同じ内容を明記した種）について、出典で確かめられた
- △ 一部：仲間全体の一般論、近縁種の記述、個人の観察・飼育記録、資料どうしの食い違いがある
- ❔ 未確認：今回の調査では出典が見つからなかった（ゲームでは一般的な生態の知識にもとづく設定）

出典の多くは自治体・博物館・研究機関・企業の一般向け解説で、学術論文まで確かめたものは一部です。ゲームでは場面に合うように場所を簡略化しています。
