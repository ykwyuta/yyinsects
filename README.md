# 昆虫図鑑 — ミクロ観察カプセルで虫をさがせ（YYInsects）

夏休みの自由研究は「昆虫図鑑」づくり。虫と同じ大きさに縮むミクロ観察カプセルに乗って、関東地方の公園や森、水辺をめぐり、昆虫を撮影して図鑑に収録します。

[YYEarth（地球史図鑑）](https://github.com/ykwyuta/YYEarth) をもとに作りました。描画・入力・記録・音声ガイドのしくみ（Rust → WebAssembly の WebGL2 / Canvas2D、Windows 版の Direct3D11 / Direct2D、IndexedDB と %APPDATA% の記録、タッチ操作、日本語・英語・中国語）と、「地図で場所を選ぶ → 降りる → 撮影して図鑑に収録 → 宿題・レーダー」という遊び方はそのままです。系統樹、大陸の移動、地質年代の移動（年表）はありません。年表の代わりに、月（季節）と時間帯を選べます。

**第1巻：関東地方の昆虫**（132種・観察スポット17か所・宿題25件）。1〜12月の**季節**と、早朝・昼・夕方・夜の**時間帯**があり、虫ごとに見られる月と時間帯がちがいます。日本のほかの地方や外国を選ぶと「準備中・待っててね」と知らせます。

## 遊ぶ・ビルドする

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く（WebGL2 が必要）。`?lang=en` / `?lang=zh` で表示言語、`?touch=1` でタッチ向けの画面を試せます。

Windows 版：`cargo run --release --bin yyinsects-win`（記録は `%APPDATA%\yyinsects\saves`）。

Cloudflare への公開は YYEarth と同じ（`bash build.sh && npx wrangler deploy`、または Pages でビルドコマンド `npm run build`・出力 `dist`）。

## ゲームの流れ

1. **地図（上空）**：日本（東経140度）を中心にしたメルカトル図法の世界地図。関東地方には、虫の観察にぴったりの**観察スポット**が光っています。押すとカプセルが飛んでいきます（`[` `]` で前・次のスポット、K で関東の全体）。
2. **季節**：地図の上の月の帯（1〜12月）で季節を変えます（`,` `.` で前・次の月）。虫は成虫が見られる月にだけ現れ、カブトムシは7〜8月、アキアカネは6〜11月、テントウムシは3〜11月（冬は成虫で越冬）、シロオビフユシャクは12〜2月です。観察の場面も季節で変わり、春は公園のサクラと田植えのあとの苗、秋は紅葉・落ち葉と黄金色の稲穂、冬は葉の落ちた林と枯れ草、冬の山や日光には雪が積もります。冬の林は葉が落ちて明るくなります。その季節に虫がいない場面では「この季節、ここに虫はいない」と知らせます。記録には、いまの月も書きます。
3. **時間帯**：月の帯の下で「早朝」「昼」「夕方」「夜」を選びます（T で切り替え）。虫は活動する時間帯にだけ現れ、カブトムシ・クワガタは早朝・夕方・夜、ヘイケボタルやオオミズアオは夜、ヒグラシは早朝と夕方、チョウやハチは昼です。空の色も変わり、早朝と夕方は低い太陽と色づいた雲、夜は月と星が出て暗くなるので、カプセルのライト（L）で照らして撮ります。夜はホタルが強く光ります。地図も時間帯に合わせて色づき、夜は暗くなります。
   - **活動しない時間も、虫はどこかで休んでいます**。季節の中なら、どの場面・どの時間帯にも虫がいます。活動しない時間の虫は「休む場所」にじっとしていて、数が少なく、葉・土・草に一部かくれているので見つけにくく、撮るには近づいてズームが要ります。
     - 葉の裏や草のかげで、はねを閉じて休む：チョウ・ガ、テントウムシ、ホタル、カメムシ
     - 草の茎や小枝の先にとまって休む：トンボ、バッタ、キリギリス、カマキリ
     - 木の幹や枝にとまったまま：セミ、カミキリムシ、タマムシ、ナナフシ、シロオビフユシャク
     - 木の根元の落ち葉や土の中にもぐる：カブトムシ、クワガタ、カナブン、センチコガネ、ハンミョウ
     - 草の根元や石のかげにひそむ：コオロギ、スズムシ、ハサミムシ
     - 巣の中・巣の入り口：ミツバチ（巣箱・木のうろ）、スズメバチ（地中の巣・つり下がった巣）、クマバチ（枯れ木の穴）、アリ（地面の穴）
     - 岸の草や浮き葉のかげ：アメンボ
   - 図鑑とレーダーにも休む場所を出します。「行く」は選んでいる時間帯を変えず、休んでいる虫のいる場所へ向かいます。
   - **成虫の季節でない月は、冬越しの姿で越冬場所にいます**。たまご・幼虫・さなぎ・冬眠中の成虫として、土の中・落ち葉の下・朽ち木の中・草の茎や枝・木の幹・水の底・巣の中・石の下・水辺の岸にいて、一年じゅう、どの場面にも虫がいます。陸の場面ではカプセルで土の断面の中までもぐれます。**たまご・幼虫・さなぎは、成虫とは別に集めます**。撮ると図鑑の「たまご・幼虫・さなぎ」のページ（84種）に収録され、成虫の収録にはなりません（成虫のまま冬を越す虫は、成虫として収録されます）。図鑑の各項目には冬越しの姿の小さな枠と「幼虫を探す」などのボタンがあり、押すと冬越しの季節の越冬場所へ向かいます。成虫を探す「行く」は、成虫の季節へ向かいます（関東で冬を越せないウスバキトンボは、冬越しの姿がありません）。宿題「冬越しのすがた」（カブトムシの幼虫・オオカマキリの卵のう・モンシロチョウのさなぎ）もあります。
     - 例：カブトムシ・ミヤマクワガタ・ノコギリクワガタ＝幼虫で土の中／カナブン＝幼虫で朽ち木の中／コクワガタ＝成虫で朽ち木の中／セミ＝幼虫で土の中（木の根の近く）／オオムラサキ・ゴマダラチョウ＝幼虫でエノキの根元の落ち葉の下／アサギマダラ＝幼虫でキジョランの葉の裏／モンシロチョウ・アゲハ類＝さなぎ／トンボ＝ヤゴで水の底（アキアカネはたまご）／ホタル＝幼虫で水の中／ゲンゴロウ・タイコウチ・ミズカマキリ＝成虫で水の底／コオイムシ・アメンボ＝成虫で岸／バッタ・コオロギ＝たまごで土の中／オオカマキリ＝卵のうで茎や枝、ハラビロカマキリ＝木の幹／テントウムシ＝成虫（ナミテントウは木のすき間で集団）／ルリタテハ＝成虫で石の下／ゴマダラカミキリ＝幼虫で生きた木の幹の中／スズメバチ＝女王が朽ち木の中／ミツバチ・アリ＝巣の中
     - 一つひとつの裏付け（出典と、確認済み・一部確認・未確認の区別、調べて直したもの）は [休む場所・冬越しの裏付け](docs/evidence.md) にまとめています。
   - 休む場所の裏付けも [docs/evidence.md](docs/evidence.md) にあります（例：カブトムシは日中、木の上や根元の土・落ち葉にもぐる／トンボは夜、草や枝にぶら下がって休む／エンマコオロギ・スズムシは昼、物かげにひそむ／ミツバチは夜、巣の中で眠る）。
4. **準備中の地域**：関東の外（北海道・東北・中部・近畿・中国・四国・九州・沖縄、伊豆諸島・小笠原、外国）を押すと、トキ先生が「〇〇の昆虫は、いま準備中です。もう少し待っててね！」と知らせます。
5. **降りる**：スポットに着いたら、左下のボタンで「雑木林」「山の森」「草はら」「公園・花だん」「池・沼」「川べり」「田んぼ」「海辺」のうち、その場所にある場面を選んで降ります。
6. **撮影**：虫を大きく・真ん中に・明るく写すと図鑑に収録されます。チョウはひらひら飛び、トンボやハチは空中で止まり、セミやカブトムシ・クワガタは木の幹にとまり（近づきすぎると飛んで逃げる）、バッタは跳ね、アメンボは水面をすべり、ゲンゴロウやミズカマキリは水の中を泳ぎます。林の中は木かげで暗いので、ライト（L）を使います。
7. **探索レーダー**：図鑑の「◎ レーダーで探す」で、その虫に会えるスポットが地図の上で光り、月の帯には見られる月と時間帯が金色で示されます。いまの季節・時間帯にいなければ「その季節へ行く」「その時間へ行く」で切り替わります。観察中は右下のレーダーに、まわりの虫と距離が出ます。
8. **宿題**：トキ先生から25の宿題が出ます（冬越しのすがた、秋の夜の鳴く虫、赤とんぼくらべ、セミの声をたどって、成虫で冬をこす虫、アシナガバチとスズメバチ、田んぼと池の小さな虫、春の訪れ、冬の虫さがし、夜の観察会、はじめての観察、公園のセミの合唱、雑木林の王者、田んぼの生きもの、草はらのバッタ、カマキリのかま、アゲハのなかま、国蝶をさがせ、トンボの王さま、水辺の光、山の虫、ハチに気をつけて、池と沼のなかま、かくれんぼ名人、宝石のような虫）。順番は自由で、「行く」を押すと目的の虫がいるスポットへカプセルが向かい、降りる場面も選ばれます。いまの季節・時間帯にいない虫なら、いちばん近い見られる月と時間帯へ移ります。

  - セミ・カメムシ 10：アブラゼミ、ミンミンゼミ、ツクツクボウシ、ニイニイゼミ、ヒグラシ、アメンボ、ミズカマキリ、タイコウチ、コオイムシ、アカスジカメムシ

図鑑の各項目には、学名・なかま（目・科）・季節・すみか・会える場所・大きさと、紹介・豆知識、日本語版では「なかまの体とくらし」「観察のコツ」「関東で会うには」の読みものがあります。すみか・季節・大きさはゲーム用のおおよそのものです（季節は月単位、時間帯は4つに分けたもので、地域や年によるずれは考えていません）。

図鑑と撮影結果には、AIで生成した写真風の画像を使っています。画像は `assets/artwork/<slug>.jpg`（成虫）と `assets/artwork/winter-<slug>.jpg`（たまご・幼虫・さなぎ）にあり、ビルド時に組み込まれます。第2弾で加えた66種（キタキチョウ〜ウスバカゲロウ）にはまだ画像がなく、図鑑でも `src/art.rs` の手描きの絵で表示します。画像を置けば自動で使われます。

観察中の虫は `src/art.rs` で描いています。`assets/units/<slug>.png`（観察用スプライト）や `assets/artwork/backdrop-<場面>.jpg`（遠景。forest・mountain・meadow・park・pond・river・paddy・shore）を置いてビルドし直すと、手描きの代わりに使われます。カプセル・石・地面の模様・トキ先生の画像は YYEarth のものを使っています。

## 地図

`assets/map/` の3枚の画像（世界・日本・関東）を、ゲームの中で色をつけて地図にします。関東の画像には環境（田畑・田んぼ・里山・山地・市街地・湖・川・海岸）と都県の番号が入っていて、地図の色分けと都県境に使います。作り直すときは `tools/make_map.py` を使います（作り方は先頭の説明を参照）。

- 世界の陸地：[Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン、[world-atlas](https://github.com/topojson/world-atlas) の land-10m）
- 日本の都道府県・湖沼・河川・市街地：国土地理院「地球地図日本」（[jpn-atlas](https://www.npmjs.com/package/jpn-atlas) に同梱の第2.2版）を加工して作成
- 山地・丘陵・田んぼの広がりは、ゲーム用に手で決めたおおよその形です

## 操作

| | マウス・キーボード | タッチ |
|---|---|---|
| 地図 | 光るスポットをクリック／`[` `]` で前・次のスポット／ドラッグや矢印キーで地図を動かす／ホイールで拡大縮小／K で関東の全体 | タップ・なぞる・2本指で拡大縮小 |
| 季節・時間帯 | 上の月の帯をクリック／`,` `.` で前・次の月／その下で時間帯を選ぶ・T で切り替え | 月の帯・時間帯のボタンをタップ・◀ ▶ |
| 降りる | Enter（左下のボタンで場面を選べる） | 「〜へ降りる」 |
| 観察 | WASD・矢印・マウスを押した方へ進む／Shift で加速／ホイール・Q/E でズーム／L でライト | 触れた方へ進む・＋－・ボタン |
| 撮影 | Space・右クリック | 撮影ボタン |
| 画面 | F1 宿題・F2 図鑑・F3 操作・Esc 地図へ／閉じる・Ctrl＋＋/－ 文字の大きさ・F11 全画面 | 上のボタン |

進み具合は自動で記録されます（ブラウザの IndexedDB。タイトル画面の「つづきから」）。操作画面からファイル（.yyisav）に書き出し・読み込みできます。記録には虫を名前（slug）で書くので、あとで虫を足しても記録はずれません。

## 読み上げ・音声ガイド

YYEarth と同じく、先生の説明・宿題・図鑑・撮影結果・遊び方を読み上げます（左上の 🔊／🔇（F5）でオン・オフ、↻（F4）で聞き直し）。日本語の誤読は `src/speech_ja.tsv` の読み辞書で補正します。`python tools/audit_readings.py --check` で、辞書に無い熟語が残っていないか調べられます（CI でも実行）。

## テスト

```
cargo test --release --lib
node --test tools/package_wasm.test.mjs tools/speech.test.mjs tools/touch.test.mjs
python tools/audit_readings.py --check
```

すべてのスポットの場面に虫がいて範囲の外へ出ないこと、すべての虫に会いに行って撮影できること、19の宿題をすべて合格できること、たまご・幼虫・さなぎは成虫と別に収録されること、季節や時間帯を変えると現れる虫が変わり記録に残ること、夜は暗くライトで明るくなること、どの場面にも一年じゅう・どの時間帯にも虫がいること、すべての虫を冬（1月）にも越冬場所で撮影できること、すべての虫を休んでいる時間帯にも撮影できること、どの月にも見られる虫がいること、関東の外を押すと「準備中」になること、地図の投影と場所の判定、記録の読み書き、すべての画面の描画、図鑑の読みもののページ分けと読み辞書などを確かめます。
