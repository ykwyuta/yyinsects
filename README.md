# 昆虫図鑑 — ミクロ観察カプセルで虫をさがせ（YYInsects）

夏休みの自由研究は「昆虫図鑑」づくり。虫と同じ大きさに縮むミクロ観察カプセルに乗って、関東地方の公園や森、水辺をめぐり、昆虫を撮影して図鑑に収録します。

[YYEarth（地球史図鑑）](https://github.com/ykwyuta/YYEarth) をもとに作りました。描画・入力・記録・音声ガイドのしくみ（Rust → WebAssembly の WebGL2 / Canvas2D、Windows 版の Direct3D11 / Direct2D、IndexedDB と %APPDATA% の記録、タッチ操作、日本語・英語・中国語）と、「地図で場所を選ぶ → 降りる → 撮影して図鑑に収録 → 宿題・レーダー」という遊び方はそのままです。系統樹、大陸の移動、地質年代の移動（年表）はありません。

**第1巻：関東地方の昆虫**（65種・観察スポット17か所・宿題15件）を収録しています。日本のほかの地方や外国を選ぶと「準備中・待っててね」と知らせます。

## 遊ぶ・ビルドする

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く（WebGL2 が必要）。`?lang=en` / `?lang=zh` で表示言語、`?touch=1` でタッチ向けの画面を試せます。

Windows 版：`cargo run --release --bin yyinsects-win`（記録は `%APPDATA%\yyinsects\saves`）。

Cloudflare への公開は YYEarth と同じ（`bash build.sh && npx wrangler deploy`、または Pages でビルドコマンド `npm run build`・出力 `dist`）。

## ゲームの流れ

1. **地図（上空）**：日本（東経140度）を中心にしたメルカトル図法の世界地図。関東地方には、虫の観察にぴったりの**観察スポット**が光っています。押すとカプセルが飛んでいきます（`,` `.` で前・次のスポット、K で関東の全体）。
2. **準備中の地域**：関東の外（北海道・東北・中部・近畿・中国・四国・九州・沖縄、伊豆諸島・小笠原、外国）を押すと、トキ先生が「〇〇の昆虫は、いま準備中です。もう少し待っててね！」と知らせます。
3. **降りる**：スポットに着いたら、左下のボタンで「雑木林」「山の森」「草はら」「公園・花だん」「池・沼」「川べり」「田んぼ」「海辺」のうち、その場所にある場面を選んで降ります。
4. **撮影**：虫を大きく・真ん中に・明るく写すと図鑑に収録されます。チョウはひらひら飛び、トンボやハチは空中で止まり、セミやカブトムシ・クワガタは木の幹にとまり（近づきすぎると飛んで逃げる）、バッタは跳ね、アメンボは水面をすべり、ゲンゴロウやミズカマキリは水の中を泳ぎます。林の中は木かげで暗いので、ライト（L）を使います。
5. **探索レーダー**：図鑑の「◎ レーダーで探す」で、その虫に会えるスポットが地図の上で光ります。観察中は右下のレーダーに、まわりの虫と距離が出ます。
6. **宿題**：トキ先生から15の宿題が出ます（はじめての観察、公園のセミの合唱、雑木林の王者、田んぼの生きもの、草はらのバッタ、カマキリのかま、アゲハのなかま、国蝶をさがせ、トンボの王さま、水辺の光、山の虫、ハチに気をつけて、池と沼のなかま、かくれんぼ名人、宝石のような虫）。順番は自由で、「行く」を押すと目的の虫がいるスポットへカプセルが向かい、降りる場面も選ばれます。

- **観察スポット（17）**：高尾山、明治神宮、井の頭恩賜公園、上野恩賜公園・不忍池、国営昭和記念公園、多摩川の河原、狭山丘陵（トトロの森）、鶴岡八幡宮（鎌倉）、筑波山、霞ヶ浦、日光・戦場ヶ原、渡良瀬遊水地、嵐山渓谷（オオムラサキの森）、成田山新勝寺、葛西臨海公園、長瀞（秩父）、養老渓谷（房総）。
- **昆虫（65）**：
  - チョウ・ガ 15：モンシロチョウ、モンキチョウ、ナミアゲハ、キアゲハ、クロアゲハ、アオスジアゲハ、オオムラサキ、ゴマダラチョウ、アカボシゴマダラ、ルリタテハ、ヤマトシジミ、ベニシジミ、アサギマダラ、ツマグロヒョウモン、オオミズアオ
  - トンボ 8：シオカラトンボ、アキアカネ、ギンヤンマ、オニヤンマ、ハグロトンボ、チョウトンボ、ウスバキトンボ、アジアイトトンボ
  - 甲虫 15：カブトムシ、ノコギリクワガタ、コクワガタ、ミヤマクワガタ、カナブン、ナナホシテントウ、ナミテントウ、ゲンジボタル、ヘイケボタル、ゲンゴロウ、ルリボシカミキリ、ゴマダラカミキリ、ヤマトタマムシ、ナミハンミョウ、オオセンチコガネ
  - セミ・カメムシ 10：アブラゼミ、ミンミンゼミ、ツクツクボウシ、ニイニイゼミ、ヒグラシ、アメンボ、ミズカマキリ、タイコウチ、コオイムシ、アカスジカメムシ
  - バッタ・カマキリ 10：トノサマバッタ、ショウリョウバッタ、オンブバッタ、エンマコオロギ、ヒガシキリギリス、スズムシ、オオカマキリ、ハラビロカマキリ、コカマキリ、ナナフシモドキ
  - ハチ・アリなど 7：セイヨウミツバチ、ニホンミツバチ、オオスズメバチ、キイロスズメバチ、キムネクマバチ、クロオオアリ、ハマベハサミムシ

図鑑の各項目には、学名・なかま（目・科）・季節・すみか・会える場所・大きさと、紹介・豆知識、日本語版では「なかまの体とくらし」「観察のコツ」「関東で会うには」の読みものがあります。すみか・季節・大きさはゲーム用のおおよそのもので、どの虫も一年じゅう会えるように簡略化しています（季節は図鑑に書いてあります）。

虫の絵は `src/art.rs` で三角形から手続き的に描いています。`assets/artwork/<slug>.jpg`（図鑑画像）や `assets/units/<slug>.png`（観察用スプライト）、`assets/artwork/backdrop-<場面>.jpg`（遠景。forest・mountain・meadow・park・pond・river・paddy・shore）を置いてビルドし直すと、手描きの代わりに使われます（Rust のコードの変更は不要）。カプセル・石・地面の模様・トキ先生の画像は YYEarth のものを使っています。

## 地図

`assets/map/` の3枚の画像（世界・日本・関東）を、ゲームの中で色をつけて地図にします。関東の画像には環境（田畑・田んぼ・里山・山地・市街地・湖・川・海岸）と都県の番号が入っていて、地図の色分けと都県境に使います。作り直すときは `tools/make_map.py` を使います（作り方は先頭の説明を参照）。

- 世界の陸地：[Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン、[world-atlas](https://github.com/topojson/world-atlas) の land-10m）
- 日本の都道府県・湖沼・河川・市街地：国土地理院「地球地図日本」（[jpn-atlas](https://www.npmjs.com/package/jpn-atlas) に同梱の第2.2版）を加工して作成
- 山地・丘陵・田んぼの広がりは、ゲーム用に手で決めたおおよその形です

## 操作

| | マウス・キーボード | タッチ |
|---|---|---|
| 地図 | 光るスポットをクリック／`,` `.` で前・次のスポット／ドラッグや矢印キーで地図を動かす／ホイールで拡大縮小／K で関東の全体 | タップ・なぞる・2本指で拡大縮小 |
| 降りる | Enter（左下のボタンで場面を選べる） | 「〜へ降りる」 |
| 観察 | WASD・矢印・マウスを押した方へ進む／Shift で加速／ホイール・Q/E でズーム／L でライト | 触れた方へ進む・＋－・ボタン |
| 撮影 | Space・右クリック | 撮影ボタン |
| 画面 | F1 宿題・F2 図鑑・F3 操作・Esc 地図へ／閉じる・Ctrl＋＋/－ 文字の大きさ・F11 全画面 | 上のボタン |

進み具合は自動で記録されます（ブラウザの IndexedDB。タイトル画面の「つづきから」）。操作画面からファイル（.yyisav）に書き出し・読み込みできます。記録には虫を名前（slug）で書くので、あとで虫を足しても記録はずれません。

## 読み上げ・音声ガイド

YYEarth と同じく、先生の説明・宿題・図鑑・撮影結果・遊び方を読み上げます（左上の 🔊／🔇（F5）でオン・オフ、↻（F4）で聞き直し）。日本語の誤読は `src/speech_ja.tsv` の読み辞書で補正します。`python tools/audit_readings.py --check` で、辞書に無い熟語が残っていないか調べられます（CI でも実行）。

## 構成

| ファイル | 内容 |
|---|---|
| `src/earth.rs` | 地図の投影（メルカトル図法）、地図の絵、関東の観察スポット、場所の判定（関東・日本のほかの地方・外国・海） |
| `src/life.rs` | 昆虫65種のデータ（なかま・大きさ・季節・すみか・スポット・ふるまい・説明） |
| `src/art.rs` | 昆虫の絵（三角形で手続き的に描く） |
| `src/dive.rs` | 観察の場面：林・草はら・公園・水辺の断面、木や草、虫の動き（ひらひら飛ぶ・空中で止まる・幹にとまる・歩く・跳ぶ・泳ぐ・水面をすべる）、写真の採点 |
| `src/mission.rs` | 宿題（トキ先生の課題） |
| `src/guide.rs` | 図鑑の読みもの |
| `src/progress.rs` | 図鑑の収録状況・宿題・場所、その記録の読み書き |
| `src/game.rs` | 画面と操作：タイトル、地図、観察、図鑑、宿題、操作説明、写真、準備中の知らせ |
| `src/gfx.rs`・`src/web.rs`・`src/platform.rs`・`web/`・`src/win/*` | ブラウザ版・Windows 版の描画・入力・記録（YYEarth から流用） |
| `tools/make_map.py` | 地図の画像を作る |
| `tools/make_icons.py` | アイコンを作る |

## テスト

```
cargo test --release --lib
node --test tools/package_wasm.test.mjs tools/speech.test.mjs tools/touch.test.mjs
python tools/audit_readings.py --check
```

すべてのスポットの場面に虫がいて範囲の外へ出ないこと、すべての虫に会いに行って撮影できること、15の宿題をすべて合格できること、関東の外を押すと「準備中」になること、地図の投影と場所の判定、記録の読み書き、すべての画面の描画、図鑑の読みもののページ分けと読み辞書などを確かめます。
